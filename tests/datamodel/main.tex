\section{Citation commands}

\textcite{knuth1984} wrote \TeX, and \textcite{lamport1994} built \LaTeX\
on top of it. In brackets, that is \parencite{knuth1984, lamport1994}.
With a prenote and a page: \autocite[see][42]{knuth1984}. In a
footnote.\footcite{shannon1948}

Only the author: \citeauthor{turing1937}. Only the year:
\citeyear{turing1937}. Several groups at once:
\cites[1]{godel1931}[173]{erdos1959}.
